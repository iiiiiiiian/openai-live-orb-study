# Scope / provenance

This folder contains the project's authored UI wrapper, public types, lifecycle adapter, scalar-input sanitation, layout CSS, documentation and UI tests. It was separated from the private finalized workspace by an explicit allowlist, not by copying that repository wholesale.

Excluded: frozen renderer, shaders, original texture, recovered/minified source kernels, application bundles, research reports/traces, capture scripts, original runtime, models and browser data. No external resource is automatically downloaded to replace them.

The UI can communicate with a separately supplied renderer, but that integration does not grant redistribution rights to it. Recovered/research materials remain redistribution-UNRESOLVED. Do not place them in this folder merely to make a public demo self-contained.

Original code is currently UNLICENSED and private pending the owner's license choice. No MIT/Apache license, ownership identity, rights clearance or registry availability is assumed. The package is not an official OpenAI/ChatGPT product and makes no original-client parity claim.
